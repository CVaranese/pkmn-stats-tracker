# Team sheets (Pokepaste / Showdown export)

- **Researched (2026-10-26, source `felixphew/pokepaste` branch `v3`, `server.go`):** `https://pokepast.es/<16 hex id>/raw` returns the export text and `/json` returns `{paste, title, author, notes}`; both set `Access-Control-Allow-Origin: *`, so the page can fetch them from the browser. Old numeric ids (`pokepast.es/1234`) are also accepted. **Tested (2026-10-26)** with the user's league paste `64b1ebbc35388025`: `/raw` sends `Access-Control-Allow-Origin: *`, CRLF line endings and two trailing spaces per line; the page fetched and parsed it in headless Edge. 404s carry no CORS header, so a missing paste shows up as a network error in the browser, not a clean 404.
- **Tested (2026-10-26):** `https://play.pokemonshowdown.com/data/pokedex.json` sends `Access-Control-Allow-Origin: *` (~520 KB). Keys are Showdown IDs (`zamazentacrowned`, `mrmimegalar`, `zoroarkhisui`), `baseStats.hp` per forme. Only Shedinja has base HP 1. Mega formes have the same base HP as the base form (checked Charizard / Charizard-Mega-X: 78). Fetched live by the page in headless Edge.
- **Researched (well known, matches checks):** max HP = floor((2·base + IV + floor(EV/4)) · level / 100) + level + 10; Shedinja is always 1. Nature doesn't affect HP. Export defaults: level 100, IVs 31, EVs 0. Checks: 252-EV Garchomp L100 = 420, L50 Blissey 252 EVs = 362.
- **Decision (2026-10-26):** a sheet applies to a player's side in a game when all six team-preview Pokémon pair with distinct sets on it (no player name needed, so one sheet covers every game that team played). Formes pair at a hyphen boundary (`Zamazenta-*` ↔ `Zamazenta-Crowned`, `Zacian-Crowned` ↔ `Zacian`, never `Mew` ↔ `Mewtwo`); exact names pair first. First matching sheet wins.
- **Guess:** formes that change base HP mid-battle (Zygarde-Complete via Power Construct) aren't handled; max HP is from the sheet's species.
- **Tested (2026-10-26):** text copied off a Pokepaste page has a ``` line before and after each set, and may include the paste URL; the parser skips both. A sheet can name the Mega forme (`Lopunny-Mega @ Lopunnite`); it still pairs with `Lopunny` at team preview (base HP 65 for both).
- **Researched (2026-10-27):** Smogon's monthly stats `https://www.smogon.com/stats/<YYYY-MM>/chaos/gen9nationaldex-1630.json` give per Pokémon `Spreads` ("Nature:hp/atk/def/spa/spd/spe" -> weight). `tools/smogon_hp.py` reduces them to 0 or 252 HP EVs (252 when spreads with 128+ HP EVs carry over half the weight): 451 Pokémon from 2026-09. The league's own sheets back the all-or-nothing rule: of 66 saved sets, only Samurott-Hisui (200), Lopunny-Mega (48), Mamoswine (72), Zamazenta (56), Azelf (56), Great Tusk (56) and Slowbro (128) sit between 8 and 248.
- **Tested (2026-10-27), leave-one-out on the 66 sets in site/ppppp/mock/:** guess each set's HP investment with its own game's sheet hidden. The site's chain (player's other sheets, then Smogon, then base stats) gets 49 / 66 right: player step 31 / 43, Smogon 18 / 23. Smogon alone gets 55 / 66. The same player changes HP EVs between games (doxsego's Tinkaton 0 / 252 / 8, Ninetales, Brute Bonnet; PotatoesAreYum's Great Tusk, Enamorus-Therian), so their other sheets predict worse than the ladder. A wrong guess at level 100 is off by 63 HP. **Decision (user, 2026-10-27):** Smogon first, then the player's other sheets, then base stats.
- Decision (2026-10-28): a sheet set with no `EVs:` line is read as "EVs unknown", not "0 EVs": its max HP is guessed (as with no sheet) and it never counts in the player's-other-sheets guess. Made for sets pieced together from a game (FingerStripes Week 1 Suicune). Showdown's export also drops the line when every EV is 0; none of the saved sheets do that (checked 2026-10-28), and those would now get a guess marked ~ instead of an exact figure.
- **Decision (2026-10-27):** a guessed max HP never counts as a sheet: max_hp_from is "other sheet" / "Smogon" / "base stats", every HP figure that used one is flagged (row.hp_est) and shown with ~; exports keep plain numbers plus the Max HP from column.
- **Guess (2026-10-27), what the game shows of a set:** the first item revealed (`-item` with no source, Frisk, Harvest, Recycle; `-enditem`; `[from] item:`) and first ability (`-ability`, `-activate|ability:`, `[from] ability:`; with Trace / Receiver the line's Pokémon has that ability and `[of]` has the copied one). `-heal` / `-immune` from an ability belong to the line's Pokémon (Water Absorb), elsewhere `[of]` is the owner (Rough Skin). Nothing more is recorded once Trick / Switcheroo / Thief / Magician / Pickpocket (item) or Skill Swap / Worry Seed / Entrainment / Mummy / Wandering Spirit / Lingering Aroma / Transform (ability) could have changed it. Tested on one synthetic log, not checked line by line on real replays.
